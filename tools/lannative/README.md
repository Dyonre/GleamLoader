# Loader source (`version.dll`)

`lannative.c` builds `version.dll`, a proxy DLL the game loads from its own folder. Every export is forwarded to the real
`System32\version.dll`. The loader inline-hooks game functions by RVA, does its work on the game thread inside a hook on
`UGameEngine::Tick` (wrapped in SEH), and refuses to patch when the live bytes differ from the expected ones. It only runs when the game was
started with `-NoEAC` (the launcher does that).

## Build

Needs MSVC Build Tools 2022 (x64) and your own copy of the game.

1. `symbols.bin` (symbol table for `hook_symbol` and the script extender) is made from the game's own PDB on your PC and is never shared:
   * build `tools\symtool` (`dotnet build -c Release`), then `symtool <path to Absolver-Win64-Shipping.exe> dumpall > symbols_all.txt`
   * set `ABSOLVER_GAME` to the game folder (the one with `Absolver.exe`), then `python gen_symbols.py symbols_all.txt symbols.bin`
     (needs `pip install pefile capstone`), run in this folder. Without arguments it prints its usage.
2. `build.bat` -> `version.dll` (the normal build). `build.bat dev` -> `version.dev.dll` (adds a developer shot runner; do not ship it).
3. Copy `version.dll` next to `Absolver-Win64-Shipping.exe`, or use the installer in `tools\installer`.

`version_exports.h` (forwarders) and `lannative_targets.h` (hook targets with their expected bytes) are generated by `gen_headers.py` and are
already in the repository.

Mod-checking tools: `test\build_tools.bat` builds `reccheck.exe`, `modscan.exe` and `ueapply.exe` (see `docs/MODDING-GUIDE.md` section 13 and
`docs/sdk/README.md`).

## Layout

* `lannative.c` - entry point, hooks, key handling, the mod loader glue.
* `*.inc` - feature modules included by `lannative.c` (mods, rows.json, plugins, content kinds, powers, NPCs, bots, map scripts, ...).
* `*.h` - pure logic and tables used by the modules.
* `AbsolverSE.h` - the plugin API header (`docs/PLUGIN-API.md`, `docs/sdk/API-REFERENCE.md`).
* `lan_logic.c`, `lan_telemetry.c` - LAN play logic and its read-only logging (`docs/HOSTING.md`).

## Keys

F1 opens the loader menu (host, join, maps, NPCs), F2 the Mods page (`docs/MODDING-GUIDE.md` section 8b). F9, F10 and F11 are developer keys,
active only while the file `LanNative\devkeys.txt` exists: F9 free camera (`LanNative\cam.txt`), F10 teleport (`LanNative\goto.txt`), F11 runs
the developer commands in `LanNative\lmtest.txt` (`docs/MODDING-GUIDE.md` section 3).
